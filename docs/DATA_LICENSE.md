# Data licence (proposal)

Two layers, so the project can stay open while keeping a path to fund itself:

| What | Licence | Why |
|---|---|---|
| Source code | **AGPL-3.0-or-later** (`LICENSE`) | Anyone can use and modify it; anyone who runs a modified version as a public service must publish their changes. |
| Open research dataset (de-identified community contributions) | **CC BY-NC 4.0** (proposed) | Free for research, education and hobby use with credit. Commercial use needs a separate licence from the maintainers. |
| Research logs and spec sheets | **CC BY 4.0** (proposed) | Free to share and quote with credit. |

Commercial licences for the dataset are only possible because contributors grant
that right in the contributor terms (`docs/CONTRIBUTOR_TERMS.md`). Data
contributed before those terms existed must not be sold.

Status: proposal. Confirm with every code owner and a lawyer before publishing.
